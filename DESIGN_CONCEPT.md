# Visual Design Concept: Manomay Kiosk Web Application

## 1. Creative Direction
- **Theme:** Modern Indian Fusion / Premium Street Food
- **Mood:** Appetizing, Vibrant, Clean, Warm, Trustworthy.
- **Aesthetic:** "Glassmorphism meets Indian Spices". High-quality food photography floating on clean, frosted glass surfaces.
- **Target Audience:**
  - **Primary:** Tech-savvy urban foodies looking for quick, hygienic street food.
  - **Secondary:** Families wants a hassle-free ordering experience.

## 2. Visual Specifications

### Color Palette
| Color | Hex Code | Psychology/Usage |
| :--- | :--- | :--- |
| **Saffron Orange** (Primary) | `#EA580C` | Stimulates appetite, energy, warmth. Used for Primary Buttons and CTAs. |
| **Slate Charcoal** (Secondary) | `#0F172A` | Modern, premium, high contrast. Used for Headings and Text. |
| **Marigold Yellow** (Accent) | `#F59E0B` | Joy, optimism, freshness. Used for warnings, badges, and highlights. |
| **Cream/Off-White** (Background)| `#F8FAFC` | Cleanliness, space, neutrality. background for content areas. |

### Typography
- **Headings:** `Playfair Display` (Serif). Elegant, traditional, premium. Adds a touch of heritage to the modern interface.
- **Body:** `Inter` (Sans-serif). Highly legible, neutral, perfect for UI elements and reading menus on screens.

### Layout & Composition
- **Spatial Arrangement:**
  - **Z-Pattern Layout:** Guides the eye from Logo (Top Left) → Navigation → Hero Image (Right) → CTA (Bottom Left).
  - **Card-Based UI:** Menu items are contained in rounded cards with soft shadows (`rounded-2xl`, `shadow-lg`) to distinct them from the background.
  - **Whitespace:** Generous padding (breathing room) to avoid clutter, crucial for a kiosk interface where touch targets need to be large.
